# CRM AgroGest — Frontend (React + Vite)

Sistema de gerenciamento de clientes (CRM) para o setor agrícola.

## Requisitos

- Node.js 18 ou superior
- npm 9 ou superior

## Instalação e Execução

```bash
cd frontend
npm install
npm run dev
```

### Build de produção

```bash
npm run build
npm run preview
```
